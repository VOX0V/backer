# Politique de sécurité

## Signaler une faille

Si tu découvres une faille de sécurité dans Backer, merci de **ne pas**
ouvrir une issue publique. Contacte plutôt le mainteneur directement
(voir le profil GitHub) en décrivant :

- le comportement observé et les étapes pour le reproduire,
- l'impact potentiel (accès non autorisé, fuite de données, déni de
  service, etc.),
- si possible, un correctif suggéré.

Une réponse sera donnée dans un délai raisonnable, et un correctif publié
avant toute divulgation publique des détails.

## Versions supportées

Seule la branche `main` (dernière image publiée) reçoit des correctifs de
sécurité.
